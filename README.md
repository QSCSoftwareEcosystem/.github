# QSC Software Ecosystem organization profile

This repository manages the public GitHub profile for the
[QSC Software Ecosystem](https://github.com/QSCSoftwareEcosystem).

## Organization profile

The content displayed on the organization homepage is maintained in
[`profile/README.md`](profile/README.md).

## Repository branding

- [`brand/README.md`](brand/README.md) — shared visual, editorial, and media
  guidance for project repositories
- [`templates/README.template.md`](templates/README.template.md) — reusable
  program-manager-friendly README starting point
- [`brand/RELEASE_READINESS.md`](brand/RELEASE_READINESS.md) — separate
  governance and validation checklist for projects preparing a release
