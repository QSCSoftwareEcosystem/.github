# QSC Software Ecosystem

The QSC Software Ecosystem brings together software, tools, workflows, and
shared practices that support the mission of the Quantum Science Center (QSC).

## Our aim

Our aim is to create an interoperable, reproducible, and sustainable software
ecosystem for quantum science. The ecosystem connects independently developed
capabilities while allowing each project and team to retain ownership of its
scientific work.

## What the ecosystem connects

- Scientific applications and algorithms
- Compilation tools
- Hybrid workflows and simulation
- Shared data, metadata, and provenance
- Agentic and AI-assisted software
- Software engineering, packaging, and sustainability
- Quantum, HPC, and experimental resources
